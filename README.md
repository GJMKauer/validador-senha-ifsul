# Validador de Senhas

Repositório contendo um validador de senhas, desenvolvido para a disciplina de Qualidade de Sistemas Computacionais.

## Como executar os testes

Siga os passos abaixo para preparar o ambiente e rodar os testes unitários:

1. **Clone o repositório e acesse a pasta:**

   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd desafio-testes-github-actions
   ```

2. **Crie e ative um ambiente virtual (Recomendável):**

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Instale as dependências do projeto:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Execute a suíte de testes com os marcadores de descrição dos testes:**
   ```bash
   pytest -v
   ```
